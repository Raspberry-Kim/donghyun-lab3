# 동현빌™ · donghyun-lab3

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23689490.svg)](https://doi.org/10.5281/zenodo.23689490)

동현빌의 역학적 조작은 동현랭으로만 가능하다. 동현랭은 한국어로 쓰는 난해한 프로그래밍 언어다. 예제를 골라 실행하면 469명이 사는 작은 마을에 홍역이나 백일해, 인플루엔자 환자 한 명이 들어오고, 사람들의 색이 하루하루 바뀌면서 유행이 번지거나 사그라드는 모습을 볼 수 있다. 백신을 누구에게 접종할지, 아픈 사람을 언제 격리할지도 동현랭 코드로 설계한다.

마을 사람들의 접촉은 현실 세계를 보여준다. 2017년 10월, 영국의 작은 도시 Haslemere에서 469명이 사흘 동안 스마트폰 앱으로 서로의 거리를 기록했고, 연구진이 그 기록을 공개했다. 동현빌은 그 5분 간격의 기록 위에서 전파를 계산한다. 접촉은 현실, 유행은 가상이다.

- **[동현빌 플레이그라운드에서 바로 실행하기](https://raspberry-kim.github.io/donghyun-lab3/)**
- **[동현랭 플레이그라운드](https://raspberry-kim.github.io/donghyun-lang/)**: 마을이 알아듣는 언어의 문법과 예제를 볼 수 있다.
- **[동현랭 GitHub](https://github.com/Raspberry-Kim/donghyun-lang)**: 언어의 실행기 소스와 명세가 있다.
- **[동현초™ · 초파리 회로실험실](https://raspberry-kim.github.io/donghyun-lab1/)**, **[동현파™ · 선충 회로실험실](https://raspberry-kim.github.io/donghyun-lab2/)**: 같은 디자인으로 만든 앞선 두 실험실이다.

네 사이트는 상단의 **동현의 작은 실험들** 메뉴로 이어져 있다. 지금 보고 있는 곳은 노란색으로 표시된다.

## 시작하기

설치할 것은 없다. 동현랭을 몰라도 준비된 예제를 고르고 실행해 보면 된다.

1. **[동현빌 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab3/)**를 연다.
2. 예제를 고른다. 처음이라면 **01 · 홍역 / 접종이 없는 마을**이나 **09 · BBC 팬데믹 / 다큐멘터리의 사흘**이 좋다.
3. **실행**을 누르고 마을을 지켜본다. macOS에서는 Command+Enter, Windows나 Linux에서는 Ctrl+Enter로도 실행된다.
4. 붉게 번지는 전염, 노란 잠복, 푸른 회복, 초록 테두리의 접종자를 보고, 아래의 유행 곡선과 실험 기록을 살펴본다. 도중에 멈추고 싶으면 **오겡끼데스까**를 누르면 된다.
5. 다른 예제를 돌려 보거나 숫자를 고쳐 보자. 접종 인원 하나만 바꿔도 결과가 달라진다. 코드는 `.dh`로, 관측 결과는 CSV로 저장할 수 있다. **20 · 빈 코드 / 직접 작성**에서 나만의 실험을 짜 볼 수도 있다.

접종 버튼이나 슬라이더는 없다. **마을을 움직이는 명령은 모두 동현랭 코드에서만 나온다.** 예제를 고르거나 코드를 고치기만 해서는 시간이 흐르지 않고, 실행할 때마다 새 마을에서 처음부터 시작한다. 실행 옆의 **10회 반복** 버튼을 누르면 같은 코드를 열 번 이어서 실행한다. 두 번째 실행부터는 매번 새 시드를 쓰므로 우연에 따라 결과가 어떻게 달라지는지 볼 수 있다. 반복 중에 다시 누르면 남은 실행을 취소한다.

모형이 어떻게 돌아가는지 궁금하다면 **모델과 출처** 탭을 열어 보자. 모델 설명, 데이터 계보, 전체 출처, 이용 안내, 글꼴과 코드 라이선스를 모두 그 안에서 읽을 수 있다.

## 화면에서 볼 수 있는 것

점 하나는 한 사람, 점의 좌표는 3일간 접촉한 사람들끼리 인접하도록 계산한 배치다. 실제 집이나 거리의 위치가 아니다. 점선으로 이어진 길은 4 m 이내에서 30분 이상 함께 기록된 사이이고, 실행 중에 잠깐 나타나는 가는 선은 지금 이 5분 동안 4 m 이내에 있는 사이다. 전파가 일어나면 불꽃이 건너가고 물결이 퍼진다.

위쪽 하늘은 시간에 따라 색이 바뀐다. 기록은 아침 7시부터 밤 11시까지만 있어서, 밤은 어두운 장면으로 건너뛴다. 밤에도 잠복기와 전염 기간은 흐르지만 새로운 만남은 없다. 이것은 집 안의 전파가 빠진다는 뜻이기도 하다.

유행 곡선은 날짜에 따라 전염 중인 사람(붉은 면적)과 잠복기인 사람(노란 면적)을 쌓고, 회복자(푸른 선)와 접종으로 면역이 생긴 사람(초록 점선)을 함께 그린다. 세로축은 실험 중 가장 큰 값에 맞춰 늘어나고 같은 실행 안에서는 줄지 않는다.

## 무엇이 실제이고 무엇이 가정인가

- **실제:** 469명, 102,831개의 거리 기록, 사흘의 시간표. 한 사람이 사흘 동안 만난 사람은 50 m 이내 평균 35명, 20 m 이내 14명, 4 m 이내 5명이다.
- **빌려 온 규칙:** 거리 d에서의 전파 위험 a·exp(−d/ρ)와 ρ = 10 m는 연구진이 다큐멘터리 모의에 쓴 것이다. 4번 병원체 "BBC 팬데믹 모의 독감"은 그 설정 그대로다.
- **문헌의 숫자:** 홍역 R₀ 15·잠복 10일·전염 8일·백신 효과 97%, 백일해 5.5·8일·21일·85%, 인플루엔자 1.3·1일·5일·50%. 각 병원체의 전파 세기는 이 접촉망 위에서 첫 환자 한 명이 평균 R₀명을 감염시키도록 보정했다.
- **동현빌의 가정:** 사흘을 되풀이하고 밤을 건너뛴다. 50 m까지의 만남을 거리에 따라 가중해 쓴다(홍역이 50 m를 날아간다는 뜻이 아니라 "같은 건물이나 거리에 있었다"의 대리 지표다). 접종은 즉시, 전부 아니면 전무로 작동한다. 격리는 전염 시작 하루 뒤에 시작된다. 나이·증상·계절의 차이는 없다.

동현빌은 어떤 지역의 유행 예측도, 접종 정책을 정하는 도구도 아니다. 실제로 기록된 469명의 3일간 접촉 기반 위에서 교과서의 숫자들이 어떻게 움직이는지 손으로 만져 보는 교육용 모형이다. 자세한 근거와 한계는 [PROVENANCE.md](PROVENANCE.md)에 있다.

## 인터넷 없이 쓰기

저장소의 `index.html`을 내려받아 브라우저로 열면 오프라인에서도 그대로 실행된다. 코드와 접촉 기록, 글꼴, 예제, 출처와 라이선스가 모두 이 파일 하나에 들어 있다.

휴대폰의 파일 미리보기 기능에서는 스크립트가 돌지 않을 때가 있다. 그럴 때는 브라우저에서 [동현빌 플레이그라운드](https://raspberry-kim.github.io/donghyun-lab3/)를 열면 된다. 외부 논문이나 동현랭 사이트로 가는 링크는 인터넷이 있어야 열린다.

## 저장소 구성

| 경로 | 내용 |
|---|---|
| `index.html` | 배포용 단일 파일. 그대로 열면 된다 |
| `src/` | 앱 소스(`app.js` 화면, `village.js` 전파 모형, `worker.js` 동현랭 명령 처리, `examples.js` 예제, `donghyun.js` 동현랭 실행기 v1.53) |
| `data/raw/` | Haslemere 원 데이터와 원 README. `data/village.json`은 앱용 가공 파일 |
| `tools/build-village.cjs` | 원 데이터 검사·압축·배치·보정 도구 (`npm run data`) |
| `examples/` | 예제 `.dh` 파일 |
| `qa/` | 검사 스크립트 (`npm test`, `npm run examples`) |
| `SPEC.md` | 동현랭 명령·관측 규약 |
| `PROVENANCE.md` | 데이터 계보, 모형의 근거와 한계 |
| `CREDITS.md` | 전체 출처·가공 내역·이용 안내 |
| `LICENSE`, `licenses/` | 코드(MIT)·데이터·글꼴의 조건 |

직접 빌드하려면 Node.js 18 이상에서 `npm run build`를 실행하면 된다. 외부 패키지는 설치하지 않는다.

## 이용 조건

앱 코드와 문서는 MIT, 글꼴은 SIL OFL이다. 접촉 기록은 Kissler 등이 공개한 Haslemere 데이터셋이며, 원 저장소 README는 코드에 GPL-3을 명시했지만 데이터 파일에는 별도 라이선스를 적지 않았다. 동현빌은 데이터를 바꾸지 않고 출처와 함께 담았고, 데이터에 자체 라이선스를 부여하지 않는다. 자세한 내용은 [CREDITS.md](CREDITS.md)와 [LICENSE](LICENSE)에 있다.

## 만든 사람

**학생들에게 꼭 보여주고 싶었던 순간**

인하대학교 의과대학 김동현 교수는 역학조사관 출신으로 백신학·감염학을 연구한다. 작은 마을에서 일어나는 유행의 순간을 실험실에 담았다. 다만, 이 모델은 실제 예측에 사용할 수 없고 접종 정책을 결정하는 도구로 사용될 수도 없다. 난해한 프로그래밍 언어인 동현랭을 기반으로 하며, 즐겁고 생산적인 개발을 계속하고자 한다.
